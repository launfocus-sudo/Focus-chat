# FOCUS CHAT WEB

Versión web de **FOCUS CHAT°** para usar tus chats cifrados desde el navegador del computador.

🔗 **Abrir:** https://launfocus-sudo.github.io/Focus-chat/

## Cómo se usa

1. Ten la app **FOCUS** en tu teléfono Android (disponible próximamente en Google Play).
2. En el computador abre la página web. Aparece un código QR.
3. En el teléfono: **FOCUS CHAT → Ajustes → Dispositivos vinculados → Vincular un dispositivo** y apunta al QR.
4. Listo: verás tus chats y podrás leer y responder desde el computador.

## Características

- Lista de chats con foto, mensajes no leídos, fijados y archivados.
- Recibir y enviar mensajes en vivo.
- Fotos, videos, audios y archivos (desde el computador puedes enviar archivos de hasta 24 MB).
- Ubicaciones y contactos como tarjetas.
- La página toma los colores del tema de tu teléfono.

## Privacidad y seguridad

- Cifrado de extremo a extremo (ECDH P-256 + AES-GCM). La llave se acuerda con el QR y nunca llega al servidor.
- El teléfono es el dueño de los chats; la web solo es un espejo.
- Los chats con candado no se comparten con la web.
- Puedes cerrar la sesión de cualquier computador desde **Ajustes → Dispositivos vinculados**.

## Requisitos

- Teléfono Android con la app FOCUS y conexión a internet.
- El teléfono debe tener FOCUS CHAT activo (puede estar en segundo plano; no lo cierres desde Recientes).
